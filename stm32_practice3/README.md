# 练习 3：GPIO输入和按键开关灯 | Practice 3: GPIO Input and Button Control LED

## 功能 | Function
- 使用阻塞式延时函数实现按键消抖。 | Use blocking delay function to implement button debouncing.
- 通过检测按键状态开关灯。 | Control LED by detecting button state.

## 硬件连接 | Hardware Connection
- LED_R 连接在 PA1 引脚。 | LED_R connected to pin PA1.
- LED_G 连接在 PA2 引脚。 | LED_G connected to pin PA2.
- LED_B 连接在 PA3 引脚。 | LED_B connected to pin PA3.
- KEY1 连接在 PC2 引脚。 | KEY1 connected to pin PC2.
- KEY2 连接在 PC3 引脚。 | KEY2 connected to pin PC3.
